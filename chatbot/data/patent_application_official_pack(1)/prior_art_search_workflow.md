# 선행기술조사 워크플로우

생성일: 2026-06-01

| 단계 | 작업 | 설명 | 팁 |
|---|---|---|---|
| 1 | 키워드 도출 | 기술명, 문제, 해결수단, 효과, 구성요소, 동의어/영문어를 분리 | 예: 무선 충전 + 열관리 + 배터리 |
| 2 | KIPRIS 통합검색 | 큰 범위를 먼저 검색해 주요 용어와 대표 문헌 파악 | 검색 결과가 많으면 결과 내 재검색 사용 |
| 3 | 특허·실용신안 상세검색 | 발명의 명칭, 요약, 청구범위, 출원인, 발명자, IPC/CPC 조건으로 좁힘 | 구문검색 "...", AND(*), OR(+), NOT(!), NEAR(^) 활용 |
| 4 | 분류 검색 | IPC/CPC를 찾아 같은 분류의 문헌을 훑음 | 키워드가 다르지만 같은 기술인 문헌 발견에 유리 |
| 5 | 인용/피인용/패밀리 | 대표 유사문헌의 인용·피인용·패밀리 문헌 확인 | 핵심 선행문헌 누락 방지 |
| 6 | 비특허문헌 검색 | 논문, 표준문서, 제품설명서, GitHub, 논문DB 등 확인 | 출원 전 공개된 기술은 신규성/진보성 리스크 |
| 7 | 차이점 표 작성 | 각 선행문헌별 구성요소와 내 발명의 차이를 표로 작성 | 청구항 설계의 근거 자료 |
| 8 | 검색결과 다운로드 | KIPRIS 온라인 다운로드로 결과를 .xls 또는 .rtf로 저장 | 시간대별 다운로드 건수 제한 확인 |

## 검색식 예시

- `핵심기술*해결문제`
- `"정확한 기술구문"`
- `동의어1+동의어2`
- `핵심기술*!제외어`
- `핵심어^2효과`
- `IPC/CPC 분류코드 + 핵심 키워드`
