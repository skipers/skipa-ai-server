# 거절 관련 원본 문서와 현재 보유 자료 구분

생성/갱신일: 2026-06-04

## 핵심 정리

현재 로컬 `downloads` 폴더에는 실제 사건별 **의견제출통지서**, **거절결정서**, **거절의견서 원본**이 없다. 보유 중인 파일은 출원 절차, 방식심사, 심사 실무, 선행기술조사, CPC, PCT 가이드 자료다.

따라서 챗봇은 다음처럼 동작해야 한다.

- 실제 거절/실패 사건 피드백: 사용자가 업로드한 통지서·의견서·거절결정서 원문을 먼저 사용한다.
- 원문이 없을 때: 현재 공식팩의 심사 기준과 절차 자료를 바탕으로 일반적인 대응 전략만 제공한다.
- “거절 사유서 원본을 찾아줘” 질문: 로컬에 원본이 없다고 말하고, 특허로/KIPRISPlus/사건 문서 업로드가 필요하다고 안내한다.

## 현재 로컬에 있는 자료

| 파일 | 포함 정보 | 원본 통지서 대체 가능 여부 |
|---|---|---|
| `13.2026 지식재산권의 손쉬운 이용.pdf` | 출원, 심사, 등록, 심판, 수수료 등 제도 안내 | 대체 불가. 절차 설명용 |
| `출원방식심사기준.pdf` | 출원서류 형식과 방식심사 기준 | 대체 불가. 형식 리스크 판단용 |
| `기술분야별 심사실무가이드 2026.03.pdf` | 기술분야별 심사 관점 | 대체 불가. 거절유형 해석 보조용 |
| `IP정보 활용 길라잡이.pdf` | 특허정보 검색과 활용 | 대체 불가. 인용문헌 재검색 보조용 |
| `CPC 매뉴얼 2020.pdf` | CPC 분류체계 | 대체 불가. 분류 검색 보조용 |
| `PCT 국제조사 및 국제예비심사 가이드라인.pdf` | PCT 국제조사/예비심사 | 대체 불가. 해외/PCT 대응 보조용 |

## 실제 사건 원본을 확보하는 방법

| 원본 종류 | 확보 방법 | 챗봇에 넣으면 좋은 이유 |
|---|---|---|
| 의견제출통지서 | 특허로 통지서 수신함 또는 사건 서류 조회/발급 | 청구항별 거절이유, 인용문헌, 제출기한을 직접 분석 가능 |
| 거절결정서 | 특허로 사건 조회/서류사본 또는 KIPRISPlus 공개 데이터 | 최종 거절 판단과 불복/재심사 가능성을 판단 가능 |
| 보정서/의견서 | 사용자가 제출했거나 준비 중인 문서 업로드 | 보정 방향이 신규사항 추가인지, 권리범위가 적절한지 검토 가능 |
| 인용문헌 PDF | 통지서에 적힌 인용문헌 번호로 KIPRIS 등에서 확보 | 선행기술 대비표와 차이점 분석 가능 |

## 챗봇 라우팅 규칙

- 질문에 `거절`, `의견제출통지`, `거절결정`, `보정`, `실패 원인`, `피드백`이 있으면 `rejection_response`로 보낸다.
- 실제 사건 파일이 없으면 “원문이 없어 일반 기준만 답변 가능”이라고 먼저 알린다.
- 실제 사건 파일이 있으면 원문에서 청구항, 거절유형, 인용문헌, 제출기한을 추출한 뒤 공식팩 기준과 연결한다.
- 실패특허 case가 선택되어 있으면 `failed_patent/<case_id>/rejection`과 `failed_patent/<case_id>/reports/latest_report.*`를 먼저 확인한다.
- 사용자가 “이 특허의 평가가 어떻게 나왔어?”라고 물으면 통지서 원본보다 최신 재평가 보고서를 우선 근거로 삼고, 통지서/사유서는 원인 보강 근거로 사용한다.

## 실패특허 case와 원본 문서의 관계

| case 폴더 | 답변에서의 의미 |
|---|---|
| `input/` | 실패특허 원본 PDF. 청구항, 명세서, 발명 요약의 기준 |
| `rejection/` | 선택 업로드한 거절의견서, 의견제출통지서, 사유서, 사람이 입력한 실패 사유 |
| `reports/latest_report.*` | eval_logic 또는 보고서 생성 에이전트가 만든 최신 평가/실패 원인 보고서 |
| `index/vectorstore/` | 위 세 자료만 들어가는 해당 case 전용 검색 인덱스 |

case가 선택되어 있지 않으면 출원 도우미는 실제 사건 분석을 시작하지 않고, 원본 PDF 업로드를 안내해야 한다.

## 답변에서 피해야 할 것

- 현재 폴더에 없는 `통지서 표준 문안집`, `의견서 서식 PDF`, `특허거절의견서.pdf`를 로컬 근거처럼 말하지 않는다.
- 공개 URL이 있다고 해서 로컬 공식팩에 다운로드된 자료처럼 표현하지 않는다.
- 사건 원본이 없는데 특정 청구항이 왜 거절됐다고 단정하지 않는다.
- 다른 실패특허 case의 통지서나 보고서를 현재 case의 근거처럼 말하지 않는다.
