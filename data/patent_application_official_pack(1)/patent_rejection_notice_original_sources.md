# 특허 거절 시 받는 원본 문서 찾기

## 핵심 정리

특허 출원이 바로 등록되지 않을 때 처음 받는 문서는 보통 ‘거절 사유서’라는 이름이 아니라 **의견제출통지서**입니다. 이 문서 안에 심사관이 본 거절이유, 인용문헌, 해당 청구항, 제출기한 등이 적힙니다.

의견서/보정서를 제출했는데도 거절이유가 해소되지 않으면 최종적으로 **거절결정서**를 받습니다. 따라서 ‘거절당하면 받는 사유서 원본’은 목적에 따라 아래 둘을 모두 확인해야 합니다.

1. 의견제출통지서: 거절 가능성이 있으니 의견·보정 기회를 주는 문서
2. 거절결정서: 거절이유가 해소되지 않았다고 판단되어 최종 거절결정을 통지하는 문서

## 공식 원본/표준 문안 위치

### 1) 특허청/지식재산처 통지서 표준 문안집
- 문서명: 통지서 표준 문안집
- 성격: 의견제출통지서 및 거절결정서 작성의 표준 사례 모음
- 공식 페이지: https://www.kipo.go.kr/ko/kpoBultnDetail.do?aprchId=BUT0000048&menuCd=SCD0200640&ntatcSeq=10148&sysCd=
- 공식 PDF 다운로드: https://www.kipo.go.kr/ko/kpoBultnFileDown.do?aprchId=BUT0000048&ntatcAtflSeq=1&ntatcSeq=10148&sysCd=
- 용도: 실제 통지서가 어떤 형식과 문안으로 작성되는지 확인

### 2) 의견(답변, 소명)서 공식 서식
- 문서명: 특허법 시행규칙 [별지 제24호서식] 의견(답변, 소명)서
- 성격: 의견제출통지서를 받은 뒤 출원인이 제출하는 대응 서식
- 다운로드: https://www.law.go.kr/flDownload.do?flNm=%5B%EB%B3%84%EC%A7%80+%EC%A0%9C24%ED%98%B8%EC%84%9C%EC%8B%9D%5D+%EC%9D%98%EA%B2%AC%28%EB%8B%B5%EB%B3%80%2C+%EC%86%8C%EB%AA%85%29%EC%84%9C%0A&flSeq=71598639
- 용도: 받은 의견제출통지서에 답변할 때 사용하는 공식 양식

### 3) 특허법 제63조 거절이유통지
- 문서명: 특허법 제63조(거절이유통지)
- 공식 페이지: https://www.law.go.kr/LSW//lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0063&lsiSeq=279827&urlMode=lsScJoRltInfoR
- 핵심: 심사관은 거절이유를 통지하고 의견서 제출 기회를 주어야 하며, 둘 이상의 청구항이 있으면 거절되는 청구항과 그 청구항의 거절이유를 구체적으로 적어야 함

### 4) KIPRISPlus 의견제출통지서 REST API
- 문서명: 지식재산처_KIPRISPlus_의견제출통지서_REST API
- 공식 페이지: https://www.data.go.kr/data/15059446/openapi.do?recommendDataYn=Y
- 용도: 공개된 출원 관련 의견제출통지서의 서지정보, 심사관정보, PDF 다운로드 주소를 XML로 확인

### 5) KIPRISPlus 거절결정서 REST API
- 문서명: 지식재산처_KIPRISPlus_거절결정서_REST API
- 공식 페이지: https://www.data.go.kr/data/15056951/openapi.do
- 용도: 거절결정서의 서지정보, 심사관정보, PDF 다운로드 주소 및 거절결정내용 확인

## 본인 사건의 진짜 원본 받는 방법

### 방법 A: 특허로 통지서 수신함
1. 특허로 접속
2. 인증서 로그인
3. My 특허로
4. 통지서/등록료 안내
5. 통지서 수신함
6. 통지서 조회 및 다운로드
7. 통지서열람기 프로그램으로 열람 및 인쇄

주의: 온라인 발송 서류를 발송일로부터 일정 기간 내 수신하지 않으면 등기우편으로 발송되어 통지서 수신함에서 조회되지 않을 수 있습니다.

### 방법 B: 증명서발급 / 서류등·초본교부신청
1. 특허로 접속
2. 조회/발급
3. 증명서발급
4. 발급신청
5. 서류등·초본교부신청(서류사본)
6. 발급 대상 서류철 선택
7. 수취방법이 온라인수령이면 증명서수신함에서 확인
8. ZIP 또는 PDF 다운로드

## 다운로드가 안 될 때

1. 통지서 수신함에서 안 보이면 발송일 기준 수신기한이 지났는지 확인
2. 특허로 증명서발급 메뉴에서 서류사본으로 다시 신청
3. 통지서열람기 설치 여부 확인
4. 첨부 참증문헌이 DRM 적용 문서인지 확인
5. 특허고객상담센터 1544-8080에 문의
6. 공개 사건의 경우 KIPRISPlus에서 의견제출통지서 또는 거절결정서 PDF API 조회

## 실제 대응 시 봐야 할 항목

- 발송일자
- 제출기한
- 출원번호
- 발명의 명칭
- 거절되는 청구항 번호
- 적용 법조문
- 인용문헌 번호
- 신규성/진보성/기재불비/명확성 등 거절유형
- 심사관의 구체적 판단 문구
- 보정 가능 범위
- 의견서만 낼지, 보정서도 같이 낼지
