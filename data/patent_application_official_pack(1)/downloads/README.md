# 다운로드 자료 보는 방법

이 폴더의 `raw/*.do` 파일은 정부/공공기관 URL endpoint 이름이 그대로 저장된 것입니다. 실제 파일 형식은 확장자가 아니라 파일 내부 MIME/signature로 판단해야 합니다.

## 빠르게 보는 방법

- `readable/` 폴더: 실제 형식에 맞춰 `.pdf`, `.html`, `.hwp`, `.hwpx`, `.exe` 이름으로 만든 바로가기입니다.
- `file_index.csv`: 원본 파일명, 보기용 파일명, 파일 종류, 여는 방법 색인입니다.
- `raw/` 폴더: 원본 그대로 저장한 파일입니다. 챗봇 인덱싱은 이 원본도 그대로 사용합니다.

## 파일 종류 요약

- exe: 4개
- html: 24개
- hwp: 13개
- pdf: 39개
- zip/hwpx: 1개

## 추천

발표나 직접 확인에는 `readable/` 폴더를 열고 PDF/HTML/HWP 파일을 보세요. `.do` 파일을 직접 더블클릭하면 macOS가 파일 종류를 몰라 깨져 보일 수 있습니다.
