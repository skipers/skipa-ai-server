# 다중 모델 엔드포인트. Amazon SageMaker AI에서는 메모리에 모델 로딩 및 엔드포인트에 대한 트래픽 패턴을 기반으로 하는 모델 확장을 관리하므로 배포 오버헤드도 줄일 수 있습니다. 다음 다이어그램은 단일 모델 엔드포인트와 비교하여 다중 모델 엔드포인트의 작동 방식을 보여줍니다. 다중 모델 엔드포인트는 CPU 및 GPU 지원 모델 호스팅을 모두 지원합니다.
