### 3. Context-based access control - Wikipedia
- URL: https://en.wikipedia.org/wiki/Context-based_access_control

**Context-based access control** (**CBAC**) is a feature of firewall software "Firewall (computing)"), which intelligently filters TCP and UDP packets based on application layer protocol session information. CBAC can be configured to permit specified TCP and UDP traffic through a firewall "Firewall (computing)") only when the connection is initiated from within the network needing protection. | Wi
